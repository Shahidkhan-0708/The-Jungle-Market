# llama.cpp / llama-cpp-python

> **Purpose:** Run Qwen3 locally with quantized CPU-friendly inference.

## Use for
- GGUF loading
- local inference
- constrained JSON/grammar output

## Requirements
- simple JSON schema
- Pydantic validation after generation
- configurable model path/context settings

## Do not
- assume every JSON Schema feature is supported
- trust generated JSON without validation
